# Student Performance Prediction Analysis Using Machine Learning and Artificial Neural Networks

## Project Description

This project investigates whether student mathematics exam scores can be predicted using demographic, social, and educational characteristics.

The project compares three different machine learning approaches:

1. Linear Regression
2. Random Forest Regressor
3. Artificial Neural Network (ANN)

The models will be evaluated and compared using standard regression metrics.

## Objectives

The main objectives of this project are:

- To explore and understand the student performance dataset.
- To preprocess the data for machine learning.
- To develop a Linear Regression baseline model.
- To develop a Random Forest Regression model.
- To develop an Artificial Neural Network.
- To compare the performance of the three models.
- To investigate which features are most important for predicting student performance.
- To perform error analysis on the model predictions.

## Dataset

The project uses the Students Performance in Exams dataset.

The dataset contains information about students' demographic, social, and educational characteristics, as well as their mathematics, reading, and writing exam scores.

Dataset source:

https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## Models

The following models will be developed and compared:

- Linear Regression
- Random Forest Regressor
- Artificial Neural Network

## Evaluation

The models will be evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
